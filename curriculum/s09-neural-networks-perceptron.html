1. From one neuron to a network

Artificial neural networks were originally designed to loosely mimic the human brain: a network of simple interconnected units, each doing a small amount of work, whose combined behavior can be surprisingly capable. The single-layer perceptron is the earliest example — just one layer, used for supervised binary classification of problems that are linearly separable (imagine being able to draw one straight line that puts every example of Class A on one side and every example of Class B on the other).

Most networks in real use today are deep neural networks: they stack many layers on top of each other. A fully-connected deep network — where every neuron in one layer connects to every neuron in the next — is essentially a stack of perceptron-like units, which is why it's sometimes called a multi-layer perceptron (MLP).

2. Anatomy of a deep neural network

Every deep neural network is built from three kinds of layers:

Input layer

Receives the raw inputs — for example, the pixel values of an image, or a set of numeric features describing an event.

Hidden layer(s)

Sit between input and output, made of artificial neurons (also called nodes). In a fully-connected network, every neuron in one layer connects to every neuron in the next, each connection carrying its own independent weight.

Output layer

Produces the final result — for example, a value indicating how likely it is that the input image shows a cat.

Weights & bias

Every connection between two neurons has a weight; every neuron also has its own bias value. These are the numbers the network actually "learns" — everything else about the architecture stays fixed during training.

Every line is a weighted connection; every circle is a neuron with its own bias.

3. What a single neuron computes (the forward pass)

Each neuron (outside the input layer) does the same two-step computation:

  1. Weighted sum: multiply every incoming activation value by its connection's weight, add them all up, then add the neuron's own bias — z = (w₁·x₁ + w₂·x₂ + … ) + bias.
  2. Activation function: pass z through a non-linear function to produce the neuron's activation value — the number it passes on to the next layer. The classic perceptron uses a simple step function (output 1 if z ≥ 0, else 0); modern deep networks commonly use functions like sigmoid or ReLU instead, chosen for how well they behave during training.
Worked micro-example

Inputs x₁ = 1, x₂ = 0.5. Weights w₁ = 0.6, w₂ = −0.2. Bias = 0.1.

z = (0.6 × 1) + (−0.2 × 0.5) + 0.1 = 0.6 − 0.1 + 0.1 = 0.6

With a step activation (threshold 0), 0.6 ≥ 0, so this neuron's activation value/output is 1.

This same weighted-sum-then-activate computation happens at every neuron in every hidden and output layer, using the previous layer's activation values as this layer's inputs. Data flows left to right — input → hidden → output — gradually transforming raw input into increasingly abstract representations. One complete left-to-right pass like this is called the forward pass.

4. How the network learns

At the start of training, weights are initialized to small random values (biases are sometimes started at zero). Training data is fed forward through the network, producing an output, which is compared against the known correct answer. The size of that difference is the error (or loss). That error is then fed backward through the network — a process known as backpropagation — to nudge every weight and bias in the direction that would have reduced the error. One full pass through the entire training dataset is called an epoch; training repeats for many epochs until the output is judged good enough to stop.

🎯
Why this matters for testing "Good enough to stop" is exactly the ML functional performance metrics from Sessions 7–8 in action — accuracy/precision/recall/F1 for classification, or MAE/MSE/RMSE for regression. Later, in Sessions 18–19, you'll test whether that learned behavior actually holds up under adversarial and metamorphic conditions, not just on the training data.

5. The perceptron: the simplest case, learned by hand

A single-layer perceptron is one neuron doing exactly the computation above, restricted to problems that are linearly separable — its decision boundary is always a straight line (in 2D) or a flat hyperplane (in higher dimensions). Because it's a single layer, there's no need to propagate error backward through hidden layers — it uses a simpler, direct rule instead. For each training example (x, target):

  1. Compute the prediction: output = step(w·x + bias)
  2. Compute the error: error = target − output (this comes out to −1, 0, or +1 for binary 0/1 labels)
  3. Update every weight: wᵢ += learning_rate × error × xᵢ, and the bias: bias += learning_rate × error

If the prediction was already correct, error is 0 and nothing changes. If it was wrong, the weights and bias shift slightly in the direction that would have made this example correct. Repeated over enough epochs, this is guaranteed to converge to zero errors — provided the data really is linearly separable.

7. One neuron isn't enough — why "deep"

A single perceptron can only separate classes that a straight line can split apart. A well-known historical example of its limit is the XOR pattern — two classes arranged so that no single straight line can ever separate them correctly. Stacking layers, combined with non-linear activation functions, is what lets a network bend and combine multiple straight-line boundaries into much more complex, non-linear decision surfaces. That's the practical reason deep networks exist: depth buys the ability to learn relationships a single-layer perceptron structurally cannot.
