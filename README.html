How this course works

Running it

Double-click start-training.bat in this folder. It starts a tiny local web server (using the Python already installed on this machine, via server.py) and opens the dashboard in your browser at http://localhost:8420. You don't need to close the command-window yourself — every open tab quietly pings the server every few seconds, and once you close the last tab (or the whole browser), the server notices within about 10 seconds and shuts itself down, which closes that window automatically.

💡
Why not just double-click index.html? You can — everything still displays. But your quiz scores and "session complete" checkmarks are saved per-page using your browser's local storage, and some browsers isolate that storage per file when there's no server involved, so your dashboard progress bar may not update reliably. The local server avoids that.

Progress tracking

Everything is stored locally in your browser (localStorage) — nothing is uploaded anywhere. Each session tracks whether you marked it complete and your latest quiz score. The dashboard reads all of that to compute your overall % and points you at your next session.

Clearing your browser's site data for localhost (or for the file itself, if you're opening files directly) will reset your progress.

Sourcing

Core structure and learning objectives are built from the official ISTQB Certified Tester AI Testing (CT-AI) v2.0 syllabus and its companion exam-structure documents. Lesson content is original writing grounded in that syllabus plus supplementary public material from sources like Microsoft Learn, Azure AI documentation, Anthropic's model documentation, ISO/IEC standards summaries, NIST's AI Risk Management Framework, and university open courseware — synthesized and cited, not copy-pasted, so the material here is safe to keep and reuse offline.
